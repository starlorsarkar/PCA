# Math Behind Principal Component Analysis (PCA)

This notebook explains the mathematical intuition behind Principal Component Analysis (PCA) from first principles.

Instead of treating PCA as a black-box sklearn function, this project derives PCA step-by-step using:
- Mean centering
- Covariance matrices
- Eigenvalues and eigenvectors
- Variance maximization
- Dimensionality reduction

The notebook also includes visualizations and manual PCA implementation using NumPy.
